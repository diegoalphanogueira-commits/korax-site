# Korax Site

Landing page comercial da Korax.

## Objetivo

Apresentar a Korax pela dor real do cliente, demonstrar o diferencial de uma IA altamente treinável e humanizada, mostrar a operação comercial por trás do WhatsApp e conduzir o visitante para duas ações principais:

1. Conversar com a própria Korax no WhatsApp.
2. Falar sobre a implantação na empresa.

## Stack

- React
- Vite
- CSS próprio
- Lucide React
- Framer Motion disponível para microinterações futuras

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
