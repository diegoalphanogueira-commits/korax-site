## Como funciona
1. Adicione o arquivo no caminho exato acima.
2. Faça commit na branch `korax-ultra-showcase`.
3. O Webflow Cloud fará o novo deploy automaticamente.
4. Quando a imagem existir, ela substitui o placeholder sem alteração adicional no componente.

Prefira `.webp` para manter boa qualidade com arquivo leve.
